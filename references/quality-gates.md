# 成片质量：检查真实结果

检查与交付范围匹配。完整包集中交付一次构图 PDF 与对页 Word，优先用共同数据、页 ID、覆盖与媒体检测验证。实际成片检查动态、声音、解码和输出规格；人工排错按具体异常定点进行。

| 关口 | 实际检查 | 不通过时 |
|---|---|---|
| 内容 | 标题承诺兑现，主张/数字/路线有依据，限定语保留 | 改相关句子及镜头；不把未定事实说成确定 |
| 主风格 | 全片主题tokens一致，允许多参考与多布局；真实画面字体、色彩、纹理、描边与经采用的golden sample协调 | 去外来皮肤，按当前tokens重画 |
| 画面 | 开场、密集信息、主风格、地图关键段、片尾的真实帧；中文可读无裁切 | 减信息或改布局，不能只缩字 |
| 运动 | 播放关键转场、行军、文字进出、媒体跨镜；乱序采样一致 | 修正时间/状态；静帧不能证明动态 |
| 节奏和重复 | 每 5–10 秒有有效内容变化；同一素材或解释离屏满 120 秒；同一成镜或动效离屏满 300 秒；指定章卡标志动画可在章卡内重复；检查紧邻重复、插片回切和跨章重复 | 调整顺序，改为下一条证据、关系或动作 |
| 地图 | 绘图组件和真实数据可追溯；核对坐标、投影、史期、路线及地点和自然地物双语标签 | 修正点位或数据；证据不足时降为定位或明确示意 |
| 声音 | 试听开头、密集段、转折、片尾；旁白清楚无双声/削波/截尾 | 调混音剪点，再查影响段 |
| 输出 | 实际解码、画幅、帧率、音轨、时长/帧数、首尾与章节符合项目 | 修复新输出，保留诊断 |

覆盖代表状态与高风险片段，再做必要最终播放/解码检查；未改部分不反复渲染。要求全片审核时代表帧不替代全量审核。变更后复查影响范围。

记录`planned / implemented / rendered / reviewed`，附本次文件、帧号/时段、结果。`reviewed`需实际查看；未能听声音明确“未试听”。工具通过不自动代表审美/事实通过。

这些不算成片：占位替代史料却不说明、缺素材留黑、截图集冒充视频、静音样片冒充带声成片、下载源码就宣称全部应用已运行。

常见SDR可用H.264、yuv420p、Rec.709与48kHz音频，按项目调整。保留原时基，不把29.97静默改成30；当前storyboard只支持整数fps，分数时基先适配工程与校验器。
