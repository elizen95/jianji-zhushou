# 统一主题风格，允许多源借鉴

## 设计权威

用户当前要求与项目已采纳的主题决定优先。86风格库是主要学习对象，提供稳定质量的成功案例；其他库的镜头、素材、动态图形同样可以参考。参考可以多个，最终输出应像同一部影片。

style-lock.json锁定的是主题参数和使用规则，不锁一个模板ID，也不阻止有理由的设计改进。先提炼适合本片的构图、色彩关系、字体、材质与节奏，再把机制移植进来；不要直接拼接不同模板默认画面。上游示例数字、地图、报纸标题不属于本片事实。

## 可变与稳定

稳定：字体角色与中文排版、颜色语义、材质/描边/阴影、光向、来源题注、Q版角色与字幕的系统、动作气质。

可变：景别、构图功能、主体、镜头路径、证据展示方式、图表类型、路线揭示、形变/遮罩/拆层/手绘/共享对象等机制，以及按旁白需要调整的节奏。不同章节可以有受控的气氛变化，但应能解释其叙事目的和与主题的关系。

静态与动态并用。严肃证据需要停留；因果关系需要动作；空间关系需要地图或镜头。不能以动效数量衡量质量，也不能为“统一”把所有镜头做成一张卡片。

## 项目记录

- reference_styles记录实际参考的来源、风格编号、commit和采用的机制，可多个；标记主要参考与辅助参考，不强制固定数量。
- tokens记录palette语义、苹方/Noto Sans SC字体及文件、字号角色、网格、安全区、材质和运动参数。
- adaptation说明如何把借来的机制画成当前主题；不能只填库名。
- 已有代表帧或短片可登记在 golden_sample，并随集中审阅交付。
- presenter 记录 Q 版透明角色的出场安排与参考尺度。文字、图表、地图避让实际角色轮廓；证据需占满画面时在时间表记隐藏。

assets/style-presets/editorial-collage.json是可编辑的主题起点，不是用户永久指定的模板。制作前按内容修改。选定并检验主题后用lock_style.py lock记录配置指纹，check用于发现无意漂移；指纹不能证明组件真的采用了tokens。

改变主题有明确创作依据或用户要求时，更新art-direction、代表镜头及关联场景，然后重新锁定。不把该过程变成每镜审批；只修受影响范围。

## 镜头与机制选择

| 信息任务 | 候选机制 | 统一方式 |
|---|---|---|
| 原件/人物/证据 | 完整大图、双语名称、关系承接、必要圈注 | 统一题注、接触阴影、材料比例 |
| 因果/机制 | 节点传递、拆层、流程展开、对象接力 | 统一线宽、对象身份、重心和落点 |
| 数量/趋势 | 同尺度增长、实物计数、排序、区间变化 | 标签/轴线与全片同体系，真实单位和基准 |
| 地理/行军 | 定位、路线渐显、分兵汇合、补给线、时间推进 | 同一投影、字体、阵营颜色语义和窗口避让 |
| 转折/对比 | 分屏、遮罩、受控形变、匹配剪辑 | 承接对象身份和视线，不突然换皮肤 |
| 结果/情绪 | 静止、慢推、留白、回看前文对象 | 节奏有呼吸，音乐/音效服务语义 |

参考的固定6秒、每词弹跳、广告快切、默认苹果/霓虹风和强制审批，只属于原项目，不自动变成本片规定。选择取决于实际内容与视觉效果。
