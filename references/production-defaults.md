# 项目设置

当前个人项目先应用[个人制作约定](personal-production-profile.md)，其R7规则覆盖通用示例。
每个项目保存一份 `production_policy` 与决定依据。既有出镜约定按项目保留；新项目的出镜与其他设置按文案决定，续作保留用户已采纳的决定。

本用户的项目先应用[个人制作约定](personal-production-profile.md)，覆盖下表的通用缺省项；特别是不露脸、Q版透明角色叠层、画面中英双语以及不烧录对白字幕。

| 设置 | 新项目做法 |
|---|---|
| 引擎 | `engine: remotion`，母版使用Remotion，镜头可配合Motion、Lottie、Canvas、SVG、Three.js |
| 画幅／帧率 | 横屏 16:9 默认 2560×1440、60fps；源视频按原速；其他规格按用户指定 |
| Q版角色 | 用户独立生成；640×360 参考容纳区透明叠加，新口播每段至少 10 秒；见[回接规则](faceless-production.md) |
| AI片段 | 已有视频先探测源长，再按语义选择窗口；待生成片段按镜头动作估时。用户已指定时长直接登记；只有明确要求先确认时才等待 |
| 已约定的时长 | 保留依据和 asset_id→秒数；会改变该约定的剪辑先解决冲突。没有固定时长约定时可正常选段，不把整段源长当成必须完整播放 |
| 字幕／语言 | 本用户默认external且不烧录，保留字幕安全带；所有新画面文字中英双语 |
| 声音 | 优先用户原声；没有配音可先估时。背景音乐、音效服务叙事，自动营销工具不覆盖已定文案或人声 |
| 风格参考 | 查看与文案匹配的实际样片或源码，优先 86 库及扩展；按[三维规则](three-blender-production.md)实现与交接，集中审阅 |
| 构图和文字审阅 | 默认一次交全片构图 PDF 和对应的可编辑 Word；按[审阅规则](qa-and-schema.md)处理；当次明确指定可省略 |

涉及AI资产的前期规划默认给提示词及素材表：GPT图片提示词、Gemini视频提示词。镜头存在视频空缺时，按 awesome-seedance 生成补缺提示词。生成任务只有在用户实际要求生成时再使用相应工具，仍不默认调用上游付费服务。

schema 8允许按项目选择presenter模式；schema 4–7旧项目照原约定读取。AI策略按实际需求设置。`ai_video.duration_confirmation_required` 默认false；需要用户先确认的项目设true。已confirmed时保存 `confirmation_basis` 与 `durations_seconds` 并校验。详细字段与旧数据迁移见[数据与审阅](qa-and-schema.md)。

缺输入时先判断是否影响当前交付：没有录音不阻止分镜，没有未使用的AI片段不产生时长问题。不能实现的镜头记录缺项并继续其余工作。
